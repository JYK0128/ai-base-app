# 최소 폴백 표준 및 단일 신뢰 원천 가이드 (Minimal Fallback & Source of Trust)

코드 수정 및 설계 과정에서 신뢰할 수 있는 데이터를 다루고(Source of Trust), 예외적 상황에 조기 대응(Fail-Fast)하며, 사용자 경험을 안정적으로 유지(Graceful Fallback)하기 위한 표준 지침임.

---

## 🏛️ 1. 단일 신뢰 원천 원칙 (Source of Trust)

중복 타입 정의와 파생 정보 간의 불일치를 예방하고, 코드 변경에 따른 부작용을 제거하기 위해 단일 신뢰 주체(Source)를 명확히 정의함.

* **API 계약 체계**:
  * `*.contract.ts` 클래스 정의를 외부 API 통신의 단일 신뢰 원천(Source)으로 설정함.
  * 입력값 검증 DTO(`*.request.dto.ts`) 및 응답 DTO(`*.response.dto.ts`)는 이 계약 클래스의 제네릭 사양을 엄격히 추종하여 작성함.
  * 생성형 API 모델은 사용 지점에서 원본 이름을 직접 참조함. `AnnouncementItem = AnnouncementPageItem` 같은 이름 재매핑 별칭은 생성하지 않음.
* **Database 스키마 체계**:
  * `CoreEntity`를 상속하여 데코레이터가 작성된 MikroORM 엔티티 클래스를 데이터베이스 모델의 단일 신뢰 원천(Source)으로 관리함.
  * Kysely Query Builder의 static 타입 추론 및 DB 마이그레이션 파일은 이 엔티티의 메타데이터 정의를 기반으로 자동 갱신 및 참조되도록 유지함.

---

## 🚨 2. 데이터 및 비즈니스 계층의 Fail-Fast 원칙

비즈니스 로직 진입 전에 데이터의 이상 여부를 조기에 발견(Fail-Fast)하여 버그 추적 비용을 최소화함.

* **환경변수 조기 검증**:
  * 데이터베이스 연결 정보, 외부 API 연동 키 등 애플리케이션 기동에 필수적인 모든 환경변수는 시작(Bootstrap) 시점에 일괄 검증함.
  * 필수 변수 누락 시 즉시 에러 로그를 노출하고 서버 구동 프로세스를 정상 종료(Fail-Fast)함.
* **데이터 원형 보존**:
  * 클라이언트 요청 정보, 서비스 응답, 데이터베이스 조회 데이터는 다음 처리 단계로 넘어가기 전 임의로 값을 채워 넣거나 추론하여 덮어쓰지 않음.
  * 데이터를 가공 및 변형하여 의도를 훼손하지 않고 원본 값을 보존하여 전달함.
* **입력값 변환(가공) 지양**:
  * 입력값은 사양을 검증(Validate)하는 대상이며, 검증 단계에서 공백 제거, 대소문자 변환, 빈 배열 필터링 등의 임의 가공 처리를 수행하지 않음.
  * 정규화 등 형식을 수정해야 할 경우, 비즈니스 경계 영역 진입 전에 명시적이고 격리된 변환 헬퍼를 활용함.
* **비즈니스 에러 즉시 노출**:
  * 예측 가능한 에러(예: 엔티티 부재, 권한 부족 등)는 비즈니스 로직 중간에 `try-catch`로 덮어 숨기지 않음.
  * `defineErrors` 및 `ExceptionGuard`를 통한 어서터(Asserter) 검증을 유스케이스 최상단에 배치하여 신속히 실패 처리함.

---

## 🎨 3. 표현 계층(UI)의 Graceful Fallback 원칙

런타임에 에러가 발생하거나 데이터를 조회 중인 조건에서도 최소한의 시각적 안정성을 사용자에게 보장함.

* **런타임 에러 격리**:
  * React/Web 컴포넌트 렌더링 시 발생한 런타임 오류는 상위 `ErrorBoundary`로 격리하여 전체 화면이 깨지는 현상을 차단함.
  * 복구 UI(재시도 버튼 및 정중한 안내 메시지)를 즉시 노출하여 동작 연속성을 복원하도록 유도함.
* **상태 시각화 보완**:
  * 비동기 데이터 로딩 중에는 Skeleton 컴포넌트를 노출하고, 조회 결과가 없을 때는 빈 화면 대신 플레이스홀더 및 안내 템플릿(Empty State)을 렌더링함.
* **대체 그래픽(Fallback Image) 제공**:
  * 외부 이미지 자원, 프로필 이미지, 썸네일 등의 로딩에 실패한 경우 브라우저 기본 깨짐 마크 대신 사전 정의된 대체 아이콘이나 기본 그래픽을 제공함.
