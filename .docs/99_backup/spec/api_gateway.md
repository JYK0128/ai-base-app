# API 게이트웨이 스펙 (요약)

## 1. 개요

* 클라이언트 요청의 단일 진입점(`platform-gateway`)으로 라우팅, 보안 및 공통 핵심 기능(Cross-cutting) 처리

## 2. 주요 기능

* **라우팅 및 버저닝**: `/api/v1` 버저닝 접두사를 기반으로 하위 마이크로서비스로 요청 라우팅 수행
* **통합 인증**: JWT 유효성 검증 및 API 레벨 데코레이터(`@Public`, `@UseGuards`)를 통한 접근 제어
* **관찰성**: Pino Logger 기반의 요청/응답 로깅 및 실시간 성능 모니터링
* **인터페이스 규격**: 입출력 DTO 타입 강제 및 Swagger 스키마 자동 구성

## 3. 기술적 요구사항

* **Swagger 문서 자동 생성**: NestJS Swagger Module을 연동하여 API 스펙 자동 노출
* **데이터 검증**: `ValidationPipe`를 통한 클라이언트 요청 본문 및 파라미터 타입 무결성 검증

## 4. 주요 라우팅 정책 (v1)

API 게이트웨이는 다음 모듈 경로들을 관리하고 해당 마이크로서비스로 라우팅을 수행합니다.

| 경로 접두사 | 설명 |
| :--- | :--- |
| `/api/v1/auth/*` | 로그인, 회원가입, 토큰 리프레시 등 인증 서비스 매핑 |
| `/api/v1/members/*` | 조직 구성원 권한 관리 및 멤버 초대 프로세스 관리 |
| `/api/v1/organizations/*` | 조직(Organization) 메타데이터 생성 및 정보 관리 |
| `/api/v1/terms/*` | 약관 문서(Terms) 조회, 버전 관리 및 동의 여부 검증 |
| `/api/v1/announcements/*` | 시스템 공지사항 작성 및 조회 관리 |
| `/api/v1/support/*` | 고객 문의/답변 및 지원 채널 관리 |
| `/api/v1/i18n/*` | 다국어(i18n) 번역 정보 조회 및 동기화 |
| `/api/v1/resource/*` | 자원 그룹 및 디렉터리 구조 관리 |
