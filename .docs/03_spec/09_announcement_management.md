# 공지사항 관리 메뉴 기능명세서 (FE)

## 1. 개요

* 플랫폼 전체 사용자 또는 파트너 조직 관리자들을 위한 긴급 시스템 점검 공지, 일반 알림, 기능 업데이트 소식 등 생성/조회/수정 기능 제공.
* 공지사항 게시 상태 및 일정 제어 기능 수행.
* 구현 파일: `web/platform-admin-web/src/routes/_protected/announcements/index.tsx` (라우트 경로: `/announcements`).

## 2. 메뉴 식별 정보

| 항목 | 값 |
| --- | --- |
| 메뉴명 | 공지사항 관리 |
| 리소스 코드 | `ANNOUNCEMENT` |
| 리소스 유형 | `MENU` |
| 리소스 범위 | `PLATFORM` |
| 경로 | `/announcements` |
| 아이콘 | `Megaphone` |
| 기본 권한 | `CREATE`, `READ`, `UPDATE`, `DELETE` |

## 3. 메뉴 목적

| 목적 | 설명 |
| --- | --- |
| 공지사항 콘텐츠 제어 | 플랫폼 운영에 필요한 알림 콘텐츠를 생성하고 수정함. |
| 노출 제어 및 상단 고정 | 중요도가 높은 긴급 공지에 대해 최상단 고정(`pinned = true`) 기능을 제공함. |
| 대상 지정 전파 | 전체 사용자(`ALL`), 파트너 조직 매니저(`PARTNER`) 등 노출 대상 세그먼트를 분리 적용함. |
| 예약 노출 | 게시 시작일(`startAt`)과 종료일(`endAt`)을 지정하여 일정 기간만 노출되도록 통제함. |

## 4. 화면 구성

### 4.1 상단 도구 바
* **추가 단추**: 새 공지사항 작성 모달 호출 수행.
* **글로벌 필터링 검색바**: 데이터 테이블 내에서 제목, 요약, 작성자, 분류, 상태 필드 검색 및 필터링 기능 제공.

### 4.2 공지사항 목록 테이블
* **열 구성**: 제목(및 요약/작성자), 분류 배지, 노출 대상 배지, 상태 배지, 게시 정보(확정 일시 및 노출 기한), 수정 시각 정보 리스트업.
* **제목 텍스트 단추**: 클릭 시 해당 공지의 실시간 렌더링 뷰를 확인하는 미리보기 모달 활성화.

### 4.3 모달
* **공지사항 편집 모달 (`AnnouncementEditorModal.tsx`)**: 제목, 요약, 카테고리, 타겟 대상, 고정 여부, 채널, 노출 기간, 본문 에디터 제공.
* **공지사항 미리보기 모달 (`AnnouncementPreviewModal.tsx`)**: 작성 서식을 실제 사용자 뷰와 동일하게 시뮬레이션하고 상세 정보(ID, 상태, 고정 상태) 조회 및 수정 진입 단추 제공.

## 5. 데이터 모델

### 5.1 공지사항 (Announcement)

| 필드 | 설명 |
| --- | --- |
| `id` | 공지사항 식별자 (UUID) |
| `title` | 공지사항 제목 |
| `content` | 공지사항 본문 (HTML/마크다운 지원) |
| `category` | 공지 분류 (`NOTICE` / `SYSTEM` / `EVENT` 등) |
| `audience` | 공지 대상 (`ALL` / `PARTNER` / `MEMBER` 등) |
| `channel` | 전송 채널 (`IN_APP` / `EMAIL` / `SMS` 등) |
| `priority` | 우선순위 (`NORMAL` / `HIGH` / `CRITICAL`) |
| `pinned` | 최상단 고정 활성화 여부 (`true` / `false`) |
| `publishedAt` | 게시 확정 및 배포 고정 일시 |
| `startAt` | 노출 시작 예약 일시 |
| `endAt` | 노출 종료 예약 일시 |

## 6. 기능 상세

### 6.1 신규 공지 등록 및 수정
* 사용자는 편집기를 통해 공지사항의 메타데이터와 본문을 입력함.
* 임시 저장(`DRAFT`) 상태로 작성하여 추후 확인 후 확정 배포하거나, 작성 즉시 배포(`PUBLISHED`) 처리 수행.

### 6.2 상단 고정 제약
* 중요 공지사항의 경우 `pinned` 스위치를 활성화하면, 사용자 메인 대시보드 리스트의 다른 모든 일반 공지사항보다 최상단에 고정 노출함.

### 6.3 노출 기간 제약
* `startAt`과 `endAt`을 입력하면 해당 기간에만 활성 상태로 판정되어 사용자 화면에 노출됨. 만료 시각(`endAt`)이 지나면 자동으로 비활성 처리됨.

## 7. 상태 판정 규칙

### 7.1 공지사항 진행 상태
| 판정 기준 | UI 표시 상태 | 설명 |
| --- | --- | --- |
| `status = DRAFT` | 임시저장 (회색 배지) | 작성 중인 상태로 사용자 화면에 노출되지 않음 |
| `status = PUBLISHED` + 노출 기간 내 | 게시 중 (초록색 배지) | 정상 노출 중인 활성 상태 |
| `status = PUBLISHED` + 노출 기간 만료 | 게시 만료 (빨간색 배지) | 노출 기간 종료로 화면에서 숨김 처리된 상태 |

## 8. 입력 검증

| 항목 | 검증 규칙 |
| --- | --- |
| 제목 | 필수 입력, 공백 제외 문자열 검증 |
| 본문 | 필수 입력, 공백 제외 문자열 검증 |
| 분류 | 필수 선택, 유효한 카테고리 값 지정 |
| 대상 | 필수 선택, 유효한 오디언스 값 지정 |
| 노출 시작일 | 선택 입력, 시작일은 종료일보다 이전 시점이어야 함 |
