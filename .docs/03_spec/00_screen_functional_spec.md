# 프론트엔드 화면 공통 및 페이지별 기능명세서

## 1. 개요

* 모노레포 플랫폼 어드민 웹 서비스(`platform-admin-web`)의 화면 공통 레이아웃 구조와 페이지별 기능명세서에 대한 통합 인덱스 역할 수행.
* 모든 개별 명세는 `08_terms_management.md`(약관 관리 사양서)의 고정밀 작성 규격을 준수하여 입력 검증, 데이터 모델, 상태 판정 규칙, API 연동 DTO 및 제약 조건을 연계 기술함.

---

## 2. 공통 UI/UX 레이아웃 명세 (Global Layout)

* 플랫폼 어드민의 모든 페이지는 `_protected.tsx` 레이아웃 라우터에 의해 인가 확인 및 통제되며, 공통 UI 프레임을 공유함.
* **좌측 내비게이션 바 (Sidebar)**:
  * 로고 영역, 메뉴 목록 및 접기/펼치기 제어 기능 제공.
  * 로그인한 관리자의 역할(Role) 및 권한 목록(`permissions`)을 참조하여 메뉴 노출 여부를 동적으로 제어함.
* **상단 헤더 (Header)**:
  * **조직/테넌트 셀렉터 (Tenant Selector)**: 로그인한 매니저가 소속된 조직 정보를 노출하고, 소속 조직 변경 시 컨텍스트를 즉시 스위칭함.
  * **사용자 프로필 드롭다운**: 현재 로그인한 관리자 이름/이메일을 노출하고 로그아웃 액션 제공.
