# 조직 관리 및 승인 메뉴 기능명세서 (FE)

## 1. 개요

* 플랫폼 관리자 포털에서 가입 신청된 파트너 조직(Organization)의 기본 설정 조회 및 관리자 정보 연동 상태 확인 기능 제공.
* 신규 신청 조직에 대한 승인/거절 처리 수행.
* 구현 파일: `web/platform-admin-web/src/routes/_protected/organizations/index.tsx` (라우트 경로: `/organizations`).

## 2. 메뉴 식별 정보

| 항목 | 값 |
| --- | --- |
| 메뉴명 | 조직 관리 및 승인 |
| 리소스 코드 | `ORGANIZATION` |
| 리소스 유형 | `MENU` |
| 리소스 범위 | `PLATFORM` |
| 경로 | `/organizations` |
| 아이콘 | `Globe` |
| 기본 권한 | `CREATE`, `READ`, `UPDATE`, `DELETE` |

## 3. 메뉴 목적

| 목적 | 설명 |
| --- | --- |
| 신규 파트너 가입 승인 | 가입 신청(`PENDING`) 상태의 신규 조직을 승인(`ACTIVE`) 또는 거절(`REJECTED`) 처리함. |
| 조직 세부 정보 모니터링 | 조직의 사업자 명칭, 등록 서브도메인 정보, 생성일 등의 정보를 일괄 관리함. |
| 파트너사 통제 조치 | 위법 행위 또는 계약 만료 파트너 조직을 비활성화(`INACTIVE`)하여 접근 권한 즉시 정지 처리함. |
| 활동 이력 추적 | 파트너사 조직 내부의 라이프사이클 이벤트 로그를 조회하여 규정 준수 여부를 검증함. |

## 4. 화면 구성

### 4.1 좌측 조직 카드 목록 패널 (`OrganizationPanel.tsx`)
* **상태 필터링 탭**: 가입 신청(`PENDING`), 승인/활성(`ACTIVE`), 일시 정지(`INACTIVE`), 반려(`REJECTED`) 상태별로 파트너사 카드를 필터링하여 노출함.
* **조직 요약 카드**: 조직 이름, 가입 시도 서브도메인, 가입 요청 시점 정보 등을 카드 형태로 배치함.

### 4.2 우측 상세 관제 뷰 패널 (`OrganizationOverviewTab.tsx`)
* **사업자 정보 영역**: 회사/조직의 고유 사업 등록 명칭, 로고, 사업자 상세 세부 메타데이터 노출.
* **승인/반려 의사결정 바**: 선택된 조직이 `PENDING` 상태일 때 화면 우측 상단에 승인(`Approve`) 및 거절(`Reject`) 버튼 바 활성화.
* **감사 타임라인 탭 (`OrganizationActivityTab.tsx`)**: 조직 생성, 상태 변경, 온보딩 진행 단계 등 조직 관련 이벤트를 타임라인 뷰로 시각화함.

## 5. 데이터 모델

### 5.1 조직 (Organization)

| 필드 | 설명 |
| --- | --- |
| `id` | 조직 고유 식별자 (UUID) |
| `name` | 조직 이름 (비즈니스 식별 명칭) |
| `subdomain` | 해당 조직에 부여된 격리 도메인 명칭 |
| `status` | 조직 현재 진행 단계 및 상태 (`PENDING`, `ACTIVE`, `INACTIVE`, `REJECTED`) |
| `createdAt` | 최초 신청 또는 가입 등록 일시 |

## 6. 기능 상세

### 6.1 신규 신청 조직 승인 (Approve)
* 관리자가 신청 대기 중인 파트너 조직의 상세 서류 및 신청 요건을 최종 확인 후 `승인` 버튼 클릭.
* 승인 완료 시, 조직 상태는 `ACTIVE`로 변경되며 연결된 최초 매니저 계정의 로그인 권한 개방 및 해당 서브도메인의 정상 라우팅 범위 편입 수행.

### 6.2 신규 신청 조직 거절 (Reject)
* 자격 미달 또는 서류 오류 등 사유 식별 시 관리자가 `거절` 버튼을 누르고 반려 사유를 입력하여 발송 처리함.
* 거절 시 해당 조직의 상태는 `REJECTED`로 설정되며, 시스템 접근이 차단됨.

### 6.3 활동 감사 이력 조회
* 우측 상세 패널의 활동 탭 진입 시, 해당 파트너 조직의 소속 매니저들이 수행한 최근 CRUD 행위 감사 로그를 API Gateway 감사 모듈과 연계하여 실시간 목록으로 표출함.

## 7. 상태 판정 규칙

### 7.1 조직 진행 상태
| 판정 기준 | UI 표시 상태 | 설명 |
| --- | --- | --- |
| `status = PENDING` | 대기 중 (노란색 배지) | 가입 신청서 접수 및 심사 대기 상태 |
| `status = ACTIVE` | 정상/승인 (초록색 배지) | 승인 완료되어 정상적으로 로그인 및 서비스 운영 중인 상태 |
| `status = REJECTED` | 승인 반려 (빨간색 배지) | 심사가 반려되어 가입 권한이 거부된 상태 |
| `status = INACTIVE` | 일시 정지 (회색 배지) | 사후 규제 조치 또는 임시 블라인드 처리된 상태 |

## 8. 입력 검증

| 항목 | 검증 규칙 |
| --- | --- |
| 조직 식별자 | 필수 입력, 유효한 UUID 형식 검사 |
| 반려 사유 (거절 시) | 선택 입력, 최대 300자 이내 작성 |

## 9. 사용자 피드백

| 상황 | 피드백 |
| --- | --- |
| 조직 승인 성공 | 토스트 메시지 출력: `해당 조직의 파트너 서비스 이용 신청을 승인했습니다.` |
| 조직 거절 완료 | 토스트 메시지 출력: `가입 신청을 반려 처리했습니다.` |
| 승인 진행 중 | 버튼 내 로딩 스피너 애니메이션 제공 및 중복 요청 방지 |

## 10. API 연동 기준

| 기능 | Method | Endpoint | DTO | 비고 |
| --- | --- | --- | --- | --- |
| 조직 목록 조회 | `GET` | `/api/v1/organizations` | `GetOrganizationsQueryDto` | 상태(`status`) 필터 조건 탑재 |
| 조직 승인 승낙 | `POST` | `/api/v1/organizations/approve` | `OrganizationActionDto` | 상태값 `ACTIVE`로 변경 및 메일 발송 수행 |
| 조직 가입 반려 | `POST` | `/api/v1/organizations/reject` | `OrganizationActionDto` | 상태값 `REJECTED`로 변경 수행 |
