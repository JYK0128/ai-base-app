# 대시보드 메뉴 기능명세서 (FE)

## 1. 개요

* 로그인된 관리자가 시스템 보호 영역으로 처음 진입하는 허브 화면임.
* 현재 로그인된 매니저의 로그인 세션 제어, 보호된 서비스의 전반적인 상태 관제, 안전한 로그아웃 기능 제공.
* 구현 파일: `web/platform-admin-web/src/routes/_protected/dashboard/index.tsx` (라우트 경로: `/dashboard`).

## 2. 메뉴 식별 정보

| 항목 | 값 |
| --- | --- |
| 메뉴명 | 대시보드 |
| 리소스 코드 | `DASHBOARD` |
| 리소스 유형 | `MENU` |
| 리소스 범위 | `ORGANIZATION` |
| 경로 | `/dashboard` |
| 아이콘 | `LayoutDashboard` |
| 기본 권한 | `READ` |

## 3. 메뉴 목적

| 목적 | 설명 |
| --- | --- |
| 세션 인증 확인 | 유효 토큰 유지 및 보호 영역 정상 진입 상태를 시각적으로 확인 처리함. |
| 세션 제어 및 로그아웃 | 사용자의 로컬 크리덴셜 소멸 및 안전한 외부 로그인 페이지로의 정상 리디렉션을 수행함. |

## 4. 화면 구성

### 4.1 대시보드 메인 영역
* **헤더**: 대시보드 타이틀 및 보호 진입점에 관한 안내 메시지 노출.
* **로그인 상태 카드**: 현재 인증이 정상 완료되었음을 나타내는 상태 정보 표시.
* **로그아웃 단추**: 카드 중앙 하단 배치, 클릭 시 클라이언트 세션을 즉시 종료함.

## 5. 데이터 모델

### 5.1 세션 및 계정 (Session / User Auth)
* **Auth Context**: 브라우저 메모리에 보관되는 Access Token 및 Refresh Token 정보.
* **로그아웃 액션**: `useAuth` 훅의 `logout()`을 호출하여 메모리 상태 소거 및 LocalStorage/Cookie 내 세션 잔재 파기 수행.

## 6. 기능 상세

### 6.1 로그인 세션 유효성 시각화
* 사용자의 본 라우트(`/dashboard`) 정상 진입은 상위 `_protected.tsx` 레이아웃 라우트의 JWT 토큰 검사(클라이언트 사이드 인가 Guard) 통과를 전제함.

### 6.2 세션 폐기 및 리디렉션
* **로그아웃 처리**: 사용자의 `Logout` 단추 클릭 시 `useAuth().logout()`이 기동되어 인가 정보가 소멸하고, 곧바로 `window.location.href = '/'`를 통해 브라우저 루트(로그인 화면)로 강제 이동됨.

## 7. 상태 판정 규칙

### 7.1 로그인 세션 상태
| 판정 기준 | UI 표시 상태 | 설명 |
| --- | --- | --- |
| JWT 토큰 유효 | `로그인 완료` 카드 활성화 | 정상적인 조작이 허용되는 세션 활성 상태 |
| JWT 토큰 만료 또는 부재 | 라우트 가드 차단 | 로그인 페이지(`/login`)로의 강제 리다이렉트 수행 |

## 8. 입력 검증

* 본 페이지는 별도의 사용자 입력 폼을 제공하지 않음.

## 9. 사용자 피드백

| 상황 | 피드백 |
| --- | --- |
| 로그아웃 클릭 | 즉각적인 세션 파기 및 루트 페이지 리디렉션 처리 수행 |

## 10. API 연동 기준

* 현재 프론트엔드 내의 로컬 크리덴셜 상태 소거(State Reset) 방식으로 작동함. 향후 백엔드 세션 무효화 API 연동 시 아래 사양을 적용함.

| 기능 | Method | Endpoint | DTO | 비고 |
| --- | --- | --- | --- | --- |
| 로그아웃/토큰 블랙리스트 | `POST` | `/api/v1/auth/logout` | 없음 | Refresh Token 무효화 및 쿠키 클리어 수행 |
